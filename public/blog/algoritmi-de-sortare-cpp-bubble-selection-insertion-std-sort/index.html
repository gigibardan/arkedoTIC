Algoritmi de Sortare în C++ pentru Gimnaziu & Olimpiadă: Bubble Sort, Selection Sort, Insertion Sort & std::sort() explicate pas cu pas

Sortarea unui vector este fundația peste jumătate dintre problemele de căutare, clasamente și statistici: nu poți aplica Căutarea Binară O(log n) dacă tabloul nu este ordonat, și nu poți afișa podiumul unui concurs fără un comparator corect. În acest ghid analizăm matematic și practic toți algoritmii de sortare ceruți la școală și la concursurile de informatică.

Răspuns Rapid (TL;DR)

În gimnaziu (N <= 1.000), algoritmii de sortare pătratici O(n²) — Bubble Sort cu oprire timpurie, Selection Sort și Insertion Sort — sunt esențiali pentru înțelegerea logicii de interschimbare și a testelor de clasă. Pentru Olimpiadă și N >= 10.000 de elemente, folosește exclusiv std::sort(v, v + n) din <algorithm>, care rulează în O(n log n) și sortează 100.000 de numere în sub 0,03 secunde.

1. Tabel Comparativ: Bubble vs. Selection vs. Insertion vs. std::sort()

Nu toți algoritmii O(n²) se comportă identic în practică. De exemplu, Selection Sort face extrem de puține interschimbări (maximum N−1 swap-uri), în timp ce Insertion Sort devine fulgerător — O(n) — dacă vectorul este deja aproape sortat!

3. Implementări C++ curate: Bubble (optimizat), Selection & Insertion Sort

În șablonul de mai jos presupunem un vector indexat de la 0 la n − 1. Observă utilizarea variabilei bool sortat în Bubble Sort (care oprește algoritmul imediat dacă într-o trecere nu s-a făcut nicio interschimbare) și salvarea lui curent în Insertion Sort pentru a evita swap-urile inutile:

Bubble Sort Optimizat, Selection Sort și Insertion Sort în C++ (0-indexed)
#include <iostream>
#include <utility> // pentru swap
using namespace std;

void bubbleSort(int v[], int n) {
    bool sortat;
    int pas = 0;
    do {
        sortat = true;
        for (int i = 0; i < n - 1 - pas; i++) {
            if (v[i] > v[i + 1]) {
                swap(v[i], v[i + 1]);
                sortat = false;
            }
        }
        pas++;
    } while (!sortat);
}

void selectionSort(int v[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int pozMin = i;
        for (int j = i + 1; j < n; j++) {
            if (v[j] < v[pozMin]) {
                pozMin = j;
            }
        }
        if (pozMin != i) swap(v[i], v[pozMin]);
    }
}

void insertionSort(int v[], int n) {
    for (int i = 1; i < n; i++) {
        int curent = v[i];
        int j = i - 1;
        while (j >= 0 && v[j] > curent) {
            v[j + 1] = v[j];
            j--;
        }
        v[j + 1] = curent;
    }
}

4. Arma secretă de Olimpiadă: std::sort() și comparatori personalizați

În C++ modern (din biblioteca <algorithm>), funcția std::sort(start, stop) folosește Introsort (un hibrid între Quicksort, Heapsort și Insertion Sort) garantat O(n log n) chiar și pe cele mai dificile cazuri de test!

Dacă vrei să sortezi descrescător, după două criterii (ex: punctaj descrescător, iar la egalitate alfabetic după nume) sau un vector de structuri struct Elev, scrii o mică funcție bool cmp(const Elev& a, const Elev& b):

Sortare cu criterii multiple folosind std::sort() în C++
#include <iostream>
#include <algorithm>
#include <string>
using namespace std;

struct Elev {
    string nume;
    int punctaj;
};

// Sortare: punctaj descrescător, apoi nume crescător (alfabetic)
bool cmp(const Elev& a, const Elev& b) {
    if (a.punctaj != b.punctaj)
        return a.punctaj > b.punctaj;
    return a.nume < b.nume;
}

int main() {
    Elev clasa[3] = { {"Ioana", 95}, {"Andrei", 100}, {"Bogdan", 95} };
    sort(clasa, clasa + 3, cmp);
    // Rezultat: Andrei (100), Bogdan (95), Ioana (95)
    for (int i = 0; i < 3; i++)
        cout << clasa[i].nume << " " << clasa[i].punctaj << "\n";
    return 0;
}
Atenție: comparatorul cmp trebuie să întoarcă STRICT < sau >, NICIODATĂ <= sau >= (altfel încalci strict weak ordering și programul poate crăpa).
Capcana indexării de la 1 vs. de la 0 la std::sort()

Dacă vectorul este citit de la 1 la n (v[1..n]), apelul corect este sort(v + 1, v + n + 1); dacă este de la 0 la n-1 (v[0..n-1]), apelezi sort(v, v + n).

✅ Checklist înainte să trimiți o problemă de sortare

  • Am verificat dacă N ≤ 1.000 (merge O(n²)) sau N > 10.000 (obligatoriu std::sort() sau vector de frecvență).
  • Am respectat indexarea corectă în limitele buclelor (0..n-1 sau 1..n) fără a accesa v[n] în afara tabloului.
  • La comparatorul custom cmp(a, b) am folosit strict < / > și niciodată <= / >=.
  • Am urmărit cel puțin un test mic în Debugger-ul Visual Trace C++ înainte de evaluare.

❓ Întrebări frecvente (FAQ)

Care este cel mai rapid algoritm de sortare din C++ pentru N = 100.000?
Funcția standard std::sort(v, v + n) din biblioteca <algorithm> (complexitate garantată O(n log n)), sau Counting Sort / vector de frecvență în O(n + maxVal) dacă numerele sunt întregi pozitive mici.
Ce înseamnă că un algoritm de sortare este „stabil”?
Un algoritm stabil (ex: Insertion Sort, Merge Sort, std::stable_sort) păstrează ordinea relativă inițială a elementelor cu valori egale. De exemplu, dacă sortezi elevi după clasă, elevii din aceeași clasă rămân în ordinea inițială.
De ce este Bubble Sort mai lent decât Insertion Sort chiar dacă ambele sunt O(n²)?
Bubble Sort face o interschimbare completă (3 atribuiri cu variabilă auxiliară) la aproape fiecare comparație inversată, în timp ce Insertion Sort doar deplasează elementele cu o singură atribuire și scrie valoarea o dată la final.
