How to Format School Reports in Word & Google Docs (Grades 5–7): Margins, Page Numbers, TOC & PDF Export

Whether you are submitting a Science lab report, a History essay, or a Grade 7 ICT document project, clean formatting separates polished work from messy drafts. Students frequently lose points over stubborn blank last pages, images jumping across paragraphs, or mismatched fonts pasted from websites. Here is the complete practical fix.

Quick Answer (TL;DR)

An A+ school paper uses A4 margins (2.5 cm / 1 inch), a consistent 12 pt font (Calibri, Arial, or Times New Roman), Justify paragraph alignment, Heading 1/2 styles for an automatic Table of Contents, "Different First Page" to hide the cover page number, and a final PDF export so layout never shifts.

1. Clean Page Setup & Stopping Images From Jumping Around

Before typing, configure your page size and margins under Layout (Word) or File -> Page setup (Google Docs). Uniform formatting across the whole paper takes seconds with Ctrl+A.

To prevent inserted diagrams from pushing text off the page, right-click the image, open Wrap Text, and switch from In Line with Text to Square or Top and Bottom so text flows neatly around it.

2. Typography & Punctuation Spacing Rules

Always attach commas, periods, colons, semicolons, exclamation marks, and question marks directly to the preceding word, followed by exactly one space afterward—never put a space before punctuation.

When pasting research notes into your draft, use Ctrl+Shift+V (Paste Without Formatting) instead of Ctrl+V so you never import grey backgrounds or mismatched web fonts.

Avoid the Empty-Enter Trap

Never press Enter 15 times to start a new section on the next page. Use Ctrl+Enter (Page Break) so adding text earlier in the paper never pushes your headings out of place.

3. Hide Page Number on Page 1 & Delete the Stubborn Blank Final Page

Two of the most searched Word frustrations have instant 15-second fixes:

  1. Hide Page 1 Number: Double-click inside the Footer -> check "Different First Page" in the Header & Footer ribbon -> delete the "1" on the cover page while keeping "2, 3, 4..." intact.
  2. Delete Trailing Blank Page: Click the ¶ (Show/Hide Formatting Marks) button on the Home tab to reveal invisible symbols -> jump to the last blank page, highlight stray ¶ marks or a Page Break tag, and press Delete.
  3. Use Clean Page Breaks: Press Ctrl+Enter whenever starting a major new section or appendix.

4. One-Click Table of Contents & Exporting Safe PDFs

Instead of typing dots and page numbers manually, highlight section titles and apply Heading 1 (and Heading 2 for subsections). Then click References -> Table of Contents -> Automatic Table (in Google Docs: Insert -> Table of contents).

Before submitting or printing, export a PDF copy via File -> Save As / Download -> PDF. Unlike .docx files that can reflow on a teacher’s computer, PDF freezes fonts, margins, and diagrams permanently.

6 Time-Saving Keyboard Shortcuts for Word & Google Docs
Ctrl + A         -> Select entire document (unify font & spacing in one step)
Ctrl + J         -> Justify alignment (crisp straight left & right margins)
Ctrl + Enter     -> Insert clean Page Break
Ctrl + Shift + V -> Paste plain text without external web formatting
Ctrl + Z         -> Undo last action
Ctrl + S         -> Save immediately
Mastering Ctrl+Shift+V and Ctrl+Enter eliminates 80% of student layout headaches.

✅ Pre-Submit Document Formatting Checklist

  • Toggled ¶ marks to remove double spaces and stacked blank Enter lines.
  • Uniform 12 pt body font and Justify alignment applied throughout.
  • Cover page number hidden with Different First Page if a title page is used.
  • Trailing blank page removed and final copy exported as PDF.

❓ Frequently Asked Questions

How do I paste text without keeping the website background color?
Press Ctrl + Shift + V (or Cmd + Shift + V on Mac) to paste plain text matching your document’s existing font and size.
Why won’t Backspace delete the blank page at the end of my Word file?
Word requires a trailing paragraph after tables or manual page breaks. Click the ¶ (Show/Hide) icon on Home to see what sits on the blank page and delete the Page Break or shrink the empty paragraph.
Why should students submit a PDF instead of only a .docx file?
A .docx file can shift pages if the receiving computer lacks the same fonts or uses a different office suite. A PDF locks every margin, image, and page number identically everywhere.
How do I start page numbering on page 2?
Double-click the footer area, check "Different First Page" on the Header & Footer tab, and delete the page number from page 1.

Operating System (OS) →
An Operating System (OS) is the core software layer that manages all hardware (CPU, RAM, storage, peripherals) and provides the graphical user interface (GUI) so users can launch apps and organize files.
Hierarchical File Tree & File Path →
A file tree is the hierarchical folder structure on a storage drive starting from a root directory (e.g., C:\ or /) down through nested subfolders. A file path specifies the exact address of a file inside that tree.
File Extension (.docx, .pdf, .cpp, .png, .exe) →
A file extension is the short suffix after the last dot in a filename (like report.pdf). It tells the operating system what type of data the file holds and which application should open it.
Document Formatting, Headings & Page Margins (Word / Docs) →
Clean document formatting relies on uniform page margins (2–2.5 cm), proper punctuation spacing (space after marks, never before), clean Page Breaks (Ctrl+Enter), and Heading styles (H1/H2) to generate an automatic Table of Contents.
Netiquette & Email Fields (To, Cc, Bcc) →
Netiquette (Internet Etiquette) is the set of respectful rules for online communication. In email, To holds primary recipients, Cc (Carbon Copy) sends visible copies to others, and Bcc (Blind Carbon Copy) hides recipients’ addresses from one another.
Cloud Computing, Backups & Real-Time Collaboration →
Cloud computing stores files and runs applications on remote internet servers rather than relying solely on your local computer drive. It enables automatic backups, version history, and simultaneous teamwork inside tools like Google Docs and OneDrive.
