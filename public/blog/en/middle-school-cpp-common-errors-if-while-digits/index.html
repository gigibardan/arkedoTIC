Middle School C++ Guide (Grades 7–8): Fixing Top 10 Errors in if, while & Digit Algorithms

Moving from drag-and-drop Scratch blocks to typing C++ in Code::Blocks is a big leap in Grades 7 and 8. Often your algorithmic logic is spot-on, yet one tiny punctuation mark or integer division rule breaks the entire output. Here are the 10 most common classroom bugs—and exactly how to fix each one.

Quick Answer (TL;DR)

Nine out of ten middle school C++ bugs come from five traps: writing = instead of == inside if(), placing a stray semicolon right after if(...) or while(...), forgetting n = n / 10 inside a digit loop (infinite loop), leaving sums uninitialized instead of int s = 0, and skipping the edge case n = 0.

2. Branching Traps: = vs ==, Range Checks, and Semicolons

Using = (assignment) instead of == (comparison) compiles without crashing, silently overwrites your variable, and breaks your logic. Likewise, chained math inequalities like 10 <= x <= 99 do not work as expected in C++; always combine two checks with logical AND (&&).

Clean Range & Equality Checks in C++
#include <iostream>
using namespace std;

int main() {
    int x;
    cin >> x;

    // WRONG: if (10 <= x <= 99);
    // RIGHT: explicit && operator and no stray semicolon
    if (x >= 10 && x <= 99) {
        cout << "Two-digit number";
    } else if (x == 0) { // RIGHT: double equals
        cout << "Zero";
    } else {
        cout << "Other number";
    }
    return 0;
}
Notice there is no semicolon after the closing parenthesis of if() or else if().

3. Digit Algorithms (% 10, / 10, Palindromes & the n = 0 Edge Case)

Almost every middle school algorithm test includes digit extraction using modulo (% 10 for the last digit) and integer division (/ 10 to drop the last digit). Always back up n into a temporary variable (int aux = n;) before destroying n in the loop, and explicitly cover n = 0.

Bulletproof Palindrome & Digit Sum Template
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int aux = n;      // 1. Save original value BEFORE the loop
    int rev = 0, sum = 0, digits = 0;

    if (n == 0) {     // 2. Handle n = 0 explicitly (1 digit)
        digits = 1;
    }

    while (n > 0) {
        int d = n % 10;      // Extract last digit
        sum = sum + d;       // Accumulate sum
        rev = rev * 10 + d;  // Build reversed number
        digits++;            // Count digit
        n = n / 10;          // Chop last digit (REQUIRED!)
    }

    cout << "Digit sum = " << sum << "\n";
    cout << "Digit count = " << digits << "\n";
    if (aux == rev)
        cout << "Palindrome!";
    else
        cout << "Not a palindrome!";

    return 0;
}
Dry-run this template on both n = 121 and n = 0 to verify every branch.
Black Console Window Frozen?

If your console opens and prints nothing, check whether you forgot n = n / 10; inside your while loop or if the program is waiting for input at cin >> n.

4. Integer vs. Floating-Point Division and the 3-Glass Swap Rule

Dividing two int values like 7 / 2 yields 3, discarding the remainder. Divide by 2.0 or cast (float)a / b whenever you need decimals. And when swapping two variables a and b, always use a third temporary variable (aux = a; a = b; b = aux;) so neither value gets overwritten.

  1. Pour glass A into empty temporary glass AUX (aux = a;).
  2. Pour glass B into now-free glass A (a = b;).
  3. Pour the saved value from AUX into glass B (b = aux;).

✅ Pre-Submit C++ Debugging Checklist

  • No stray semicolon ; immediately after any if(...) or while(...).
  • All equality checks use == instead of =.
  • Accumulators start at 0 for sums and 1 for products.
  • Every while loop updates its condition variable toward termination.
  • Tested edge cases: n = 0, single-digit numbers, and boundary values.

❓ Frequently Asked Questions

Why does my C++ program print huge random numbers like 4199040?
You declared a local variable (like int sum;) without initializing it (= 0). Uninitialized local variables in C++ hold whatever random bytes were previously in RAM.
Why does Code::Blocks highlight a line that looks completely valid?
Forgetting a semicolon at the end of one statement makes the compiler report an error on the following line. Always check the line directly above the red indicator.
What is the difference between / and % in C++?
Integer division / gives the quotient (247 / 10 = 24, dropping the last digit), while modulo % gives the remainder (247 % 10 = 7, extracting the last digit).
When should I pick for vs. while in school exercises?
Use a for loop when the iteration count is known upfront (e.g., 1 to n or looping through an array). Use while when repetition depends on a changing condition (e.g., dividing n by 10 until n reaches 0).

🔤 ICT Glossary Terms Used in This Guide

All 44 Terms A–Z →
Algorithm & Core Algorithm Properties →
An algorithm is a finite, unambiguous, step-by-step set of instructions that transforms input data into the desired output within a finite number of steps.
Variable & C++ Data Types (int, double, char, bool) →
A variable is a named container in RAM that holds a value which can change while a program runs. In C++, every variable must be declared with a specific data type before use.
Modulo (%) & Integer Division (/) in C++ →
When both operands are integers in C++, / computes the integer quotient (discarding decimals), while modulo % returns the remainder. Together with base 10 (% 10 and / 10), they power digit-extraction and divisibility algorithms.
Assignment (=) vs. Equality Check (==) in C++ →
A single equals sign (=) is the assignment operator that stores a value into a variable (x = 5). Double equals (==) is the comparison operator that tests whether two values are equal (x == 5).
Conditional Branching (if / else & switch) in C++ →
Conditional branching lets a program choose between different execution paths depending on whether a logical condition is true or false (if / else), or by matching discrete constant values (switch).
while vs. do-while Loops in C++ →
Both while and do-while repeat code as long as a condition holds true. A while loop checks the condition first (may run 0 times), whereas a do-while loop checks at the end (always runs at least once).
