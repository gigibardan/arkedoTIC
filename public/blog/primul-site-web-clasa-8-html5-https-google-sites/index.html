Primul tău site web în Clasa a VIII-a: Structura HTML5, HTTPS și publicare sigură în Google Sites

Unul dintre cele mai practice capitole din clasa a VIII-a este realizarea primului site web. Elevii învață cum citește browserul codul HTML5 din spatele oricărei pagini, de ce este obligatoriu protocolul criptat HTTPS și cum publică un site structurat cu mai multe pagini în Google Sites. Răspuns Rapid (TL;DR)

Orice pagină web modernă se bazează pe HTML5 semantic (<!DOCTYPE html>, <head> pentru metadate și <body> pentru conținut vizibil cu <header>, <nav>, <main>, <footer>). 1. Anatomia completă a unei pagini HTML5 (pe care trebuie să o știi pe de rost)

HTML5 (HyperText Markup Language) nu este un limbaj de programare ca C++, ci un limbaj de marcare care descrie structura unei pagini web folosind etichete (tag-uri) pereche: <etichetă>conținut</etichetă>.

Zona <head> conține informații invizibile pe ecran (setul de caractere UTF-8 pentru diacritice românești, titlul filei din browser și descrierea pentru Google), iar zona <body> conține tot ce vede vizitatorul: meniu, titluri, texte, imagini și linkuri.

Șablon complet HTML5 semantic pentru proiectul de clasa a VIII-a
<!DOCTYPE html>
<html lang="ro">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Proiectul meu de Robotică | Clasa a VIII-a</title>
  <meta name="description" content="Portofoliu școlar cu proiecte Arduino și experimente STEM.">
</head>
<body>
  <header>
    <h1>Atelierul de Tehnologie</h1>
    <nav>
      <a href="index.html">Acasă</a> |
      <a href="proiecte.html">Proiecte</a>
    </nav>
  </header>

  <main>
    <section>
      <h2>Ce am construit semestrul acesta</h2>
      <p>Prima mea pagină web scrisă curat în HTML5 semantic.</p>
      <img src="robot.jpg" alt="Prototip robot Arduino cu senzor ultrasonic">
    </section>
  </main>

  <footer>
    <p>© 2026 Proiect TIC Clasa a VIII-a</p>
  </footer>
</body>
</html>
Observă <meta charset="utf-8"> plasat chiar la început pentru diacritice românești corecte și atributul alt="" pe imagine.

2. HTTP vs. HTTPS, URL-uri și legături relative vs. absolute

Protocolul HTTP trimite textul dintre browser și server „în clar”, astfel încât oricine din rețeaua Wi-Fi publică îl poate citi. HTTPS adaugă criptare SSL/TLS și un certificat digital care confirmă identitatea site-ului.

Când legi paginile propriului site între ele, folosește căi relative (de exemplu href="proiecte.html"), ca site-ul să meargă și dacă îl muți pe alt server sau folder. Pentru linkuri externe spre alte site-uri, folosește calea absolută completă cu https://.

3. Cum publici un site curat cu mai multe pagini în Google Sites

Pentru proiectele de grup sau portofolii rapide, Google Sites oferă un editor vizual WYSIWYG („ce vezi este ceea ce obții”) găzduit direct pe HTTPS gratuit:

  1. Deschide sites.google.com și pornește un site nou cu o temă clară și contrast bun între fundal și text.
  2. Creează cel puțin 3 pagini din tab-ul Pages (ex: Acasă, Resurse / Proiect, Contact) pentru o navigare logică în meniul de sus.
  3. Folosește blocuri predefinite pentru a alinia echilibrat imagine + text explicativ și integrează la nevoie o hartă Google Maps, un document Google Docs sau un formular Google Forms.
  4. Verifică previzualizarea atât pe Desktop, cât și pe Telefon (butonul Preview) înainte de publicare.
  5. Apasă Publish -> alege o adresă web ușor de reținut și verifică permisiunile („Anyone can find and view” doar dacă nu ai date personale!).

4. Reguli de aur de SEO și siguranță GDPR pentru site-uri școlare

Un site public pe Internet poate fi văzut de oricine. De aceea, încă din gimnaziu trebuie să respecți câteva reguli esențiale de design, vizibilitate și protecție a datelor:

  • Nu publica pe un site public numărul tău de telefon, adresa de acasă sau fotografii fără acordul colegilor și părinților.
  • Dă fișierelor imagini nume descriptive (robot-arduino.jpg, nu IMG_20260412.jpg) și optimizează-le să nu aibă 10 MB fiecare.
  • Scrie un <title> unic pentru fiecare pagină și păstrează meniurile de navigare simple (4–6 linkuri clare).

✅ Checklist înainte să predai site-ul la Clasa a VIII-a

  • Fiecare pagină HTML are <!DOCTYPE html>, <meta charset="utf-8"> și un <title> descriptiv.
  • Toate linkurile din meniu merg corect între pagini fără erori 404.
  • Fiecare imagine are atribut alt completat și se încarcă rapid.
  • Site-ul nu conține date personale sensibile și arată lizibil atât pe PC, cât și pe mobil.

❓ Întrebări frecvente (FAQ)

Care este diferența dintre HTML și CSS?
HTML definește structura și conținutul paginii (titluri, paragrafe, imagini, linkuri — „scheletul”), iar CSS controlează designul vizual (culori, fonturi, spațieri, așezare pe coloane).
De ce apar caractere ciudate (Ã®n loc de ă, ș, ț) într-o pagină HTML?
Lipsește eticheta <meta charset="utf-8"> din zona <head> sau fișierul HTML nu a fost salvat cu codificare UTF-8 în editorul de text.
Este gratuit să public un proiect școlar în Google Sites?
Da, Google Sites este complet gratuit cu un cont Google/școlar și include automat găzduire securizată prin HTTPS.
De ce este important atributul alt pe imaginile dintr-o pagină web?
Atributul alt oferă o descriere text pentru persoanele care folosesc cititoare de ecran, apare dacă imaginea nu se poate încărca și ajută motoarele de căutare să înțeleagă ce conține fotografia.

Pixel, Rezoluție și Modelul de Culoare RGB (0–255) →
Pixelul (Picture Element) este cel mai mic punct colorat care alcătuiește o imagine digitală sau ecranul monitorului. În modelul RGB, fiecare pixel combină trei culori de lumină — Roșu (Red), Verde (Green) și Albastru (Blue) — cu intensități între 0 și 255.
HTML5 și Etichete Semantice (<header>, <main>, <article>, <img>) →
HTML5 (HyperText Markup Language) este limbajul de marcare care construiește structura oricărei pagini web folosind etichete (tag-uri). Etichetele semantice (<header>, <nav>, <main>, <footer>) le explică motoarelor de căutare și cititoarelor de ecran ce rol are fiecare secțiune.
Protocol HTTP vs. HTTPS (Criptare SSL/TLS) →
HTTP este protocolul prin care browserul cere pagini de la un server web în text simplu necriptat. HTTPS (HTTP Secure) adaugă criptare SSL/TLS (simbolul lacătului din browser), protejând parolele și datele tale pe drumul prin rețea.
Adresa IP (IPv4 / IPv6) și Serverul DNS →
Adresa IP (Internet Protocol) este adresa numerică unică a fiecărui dispozitiv conectat la o rețea (ex. 192.168.1.15). Serverul DNS (Domain Name System) este „agenda telefonică” a Internetului care traduce numele ușor de reținut (arkyedu.com) în adresa IP numerică a serverului.
Cloud Computing, Backup și Colaborare (Google Drive / OneDrive) →
Cloud Computing înseamnă salvarea fișierelor și rularea aplicațiilor pe servere securizate accesibile prin Internet, în locul stocării exclusive pe hard-diskul local. Permite colaborarea în timp real mai multor elevi pe același document și recuperarea istoricului versiunilor.
