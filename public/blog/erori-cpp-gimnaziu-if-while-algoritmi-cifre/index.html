C++ pentru gimnaziu (Code::Blocks, clasele VII–VIII): Top 10 erori la if, while și algoritmi pe cifre

Trecerea de la blocurile vizuale din Scratch la tastarea codului C++ în Code::Blocks este unul dintre cele mai dificile momente din clasele a VII-a și a VIII-a. De multe ori, logica din mintea ta este corectă, dar un singur semn de punctuație sau o împărțire întreagă strică tot rezultatul. Am strâns cele mai întâlnite 10 erori de la lucrări, teme și concursuri — împreună cu soluția exactă pentru fiecare.

Răspuns Rapid (TL;DR)

Majoritatea problemelor C++ la gimnaziu provin din 5 capcane clasice: scrierea lui = (atribuire) în loc de == (egalitate) în if, punerea unui ; chiar după paranteza if(...) sau while(...), uitarea actualizării lui n = n / 10 în buclă (buclă infinită), neinițializarea sumei s = 0 și netratarea cazului special n = 0 la algoritmii pe cifre.

2. Capcanele structurii if / else: = vs ==, intervale și acolade

Cea mai perfidă greșeală din C++ este să confunzi operatorul de atribuire (=) cu operatorul de comparație (==). Compilatorul nu dă eroare de sintaxă dacă scrii if (x = 0) — pur și simplu pune 0 în x, vede că valoarea e falsă și nu mai intră niciodată în if.

O altă greșeală clasică vine din matematică: în caiet scriem 10 <= x <= 99 pentru numere de două cifre, dar în C++ trebuie să legi explicit cele două condiții cu operatorul logic ȘI (&&): x >= 10 && x <= 99.

Exemplu corect vs. greșit pentru interval și egalitate
#include <iostream>
using namespace std;

int main() {
    int x;
    cin >> x;

    // GRESIT: if (10 <= x <= 99);
    // CORECT: fara ';' dupa paranteza si cu operatorul &&
    if (x >= 10 && x <= 99) {
        cout << "Numar de 2 cifre";
    } else if (x == 0) { // CORECT: == cu doua semne egal
        cout << "Zero";
    } else {
        cout << "Alt numar";
    }
    return 0;
}
Observă lipsa punctului și virgulei după paranteze și folosirea acoladelor { } pentru claritate.

3. Algoritmii pe cifre (suma, oglinditul, palindromul și cazul n = 0)

În clasa a VII-a și la admiterea în clasa a IX-a, aproape orice test conține prelucrarea cifrelor unui număr natural cu ajutorul operatorilor % 10 (ultima cifră) și / 10 (eliminarea ultimei cifre).

Cele două greșeli fatale sunt: să uiți copia numărului inițial (int aux = n;) atunci când verifici dacă numărul este palindrom și să uiți cazul n = 0 atunci când numeri cifrele.

Șablon complet verificat pentru Palindrom & Suma Cifrelor
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int aux = n;      // 1. Salvam copia lui n INAINTE de while!
    int ogl = 0, suma = 0, nrCifre = 0;

    if (n == 0) {     // 2. Cazul special n = 0 are 1 cifra!
        nrCifre = 1;
    }

    while (n > 0) {
        int c = n % 10;       // Extragem ultima cifra
        suma = suma + c;      // Adunam la suma
        ogl = ogl * 10 + c;   // Construim oglinditul
        nrCifre++;            // Numaram cifra
        n = n / 10;           // Taiem ultima cifra (OBLIGATORIU!)
    }

    cout << "Suma cifrelor = " << suma << "\n";
    cout << "Numar cifre = " << nrCifre << "\n";
    if (aux == ogl)
        cout << "Este palindrom!";
    else
        cout << "Nu este palindrom!";

    return 0;
}
Rulează mental acest cod pentru n = 121 și pentru n = 0 ca să verifici ambele ramuri.
De ce se blochează Code::Blocks cu ecran negru?

Dacă fereastra de consolă rămâne neagră fără să afișeze nimic, verifică dacă ai uitat n = n / 10; în interiorul buclei while sau dacă programul așteaptă să tastezi o valoare la cin >> n.

4. Împărțirea întreagă vs. reală și interschimbarea (Regula celor 3 pahare)

În C++, dacă împarți două numere întregi (de exemplu int a = 7, b = 2; float r = a / b;), rezultatul va fi 3, nu 3.5! Pentru a obține parte zecimală, cel puțin un operand trebuie să fie real: (float)a / b sau împărțirea la 2.0.

Iar când trebuie să interschimbi două variabile a și b (frecvent la ordonări și la maxim/minim), nu scrie niciodată a = b; b = a; deoarece pierzi valoarea lui a. Ai nevoie de un „al treilea pahar” temporar: aux = a; a = b; b = aux;.

  1. Torni conținutul paharului A în paharul gol AUX (aux = a;).
  2. Torni conținutul paharului B în paharul A acum liber (a = b;).
  3. Torni valoarea salvată din AUX în paharul B (b = aux;).

❓ Întrebări frecvente (FAQ)

De ce îmi afișează programul C++ doar numere ciudate mari (ex: 4199040)?
Ai declarat o variabilă (de exemplu int suma;) fără să o inițializezi cu 0 (int suma = 0;). În C++, variabilele locale neinițializate păstrează date reziduale aleatorii din memoria RAM.
Cum rezolv eroarea de compilare când Code::Blocks indică o linie care pare corectă?
În C++, lipsa punctului și virgulei (;) la finalul unei instrucțiuni determină compilatorul să raporteze eroarea pe linia URMĂTOARE. Verifică întotdeauna linia de deasupra celei subliniate cu roșu.
Care este diferența dintre % și / în C++?
Operatorul / oferă câtul împărțirii întregi (de exemplu 247 / 10 = 24, elimină ultima cifră), iar operatorul % (modulo) oferă restul împărțirii (247 % 10 = 7, extrage ultima cifră).
Când folosesc while și când folosesc for în gimnaziu?
Folosește for când știi exact de câte ori se repetă pașii (de exemplu parcurgerea numerelor de la 1 la n sau elementele unui vector). Folosește while când nu știi dinainte numărul de pași (de exemplu prelucrarea cifrelor unui număr până când n devine 0).

Algoritm și Proprietățile Algoritmilor →
Un algoritm este o succesiune finită, clară și ordonată de pași logici care pornește de la date de intrare și produce un rezultat corect (date de ieșire) într-un timp finit, pentru orice set valid de date.
Variabilă & Tipuri de Date în C++ (int, float, char, bool) →
O variabilă este o „cutie” numită din memoria RAM care păstrează o valoare ce se poate modifica pe parcursul programului. În C++, fiecare variabilă trebuie declarată cu tipul ei de date înainte de utilizare.
Operatorul Modulo (%) și Împărțirea Întreagă (/) în C++ →
În C++, când împarți două numere întregi, operatorul / calculează câtul întreg (fără zecimale), iar operatorul modulo % calculează restul împărțirii. Împreună cu baza 10 (% 10 și / 10), stau la baza tuturor algoritmilor pe cifre.
Atribuire (=) vs. Comparare Egalitate (==) în C++ →
Un singur egal (=) este operatorul de atribuire care pune o valoare într-o variabilă (x = 5). Egalul dublu (==) este operatorul relațional care verifică dacă două valori sunt egale (x == 5), returnând adevărat sau fals.
Structura Alternativă (if / else și switch) în C++ →
Structura alternativă permite programului să ia decizii și să execute ramuri diferite de cod în funcție de o condiție logică (if / else) sau de valoarea exactă a unei variabile întregi/caracter (switch).
Bucla while vs. do-while în C++ →
Atât while, cât și do-while repetă un bloc de instrucțiuni cât timp o condiție rămâne adevărată. Diferența majoră este că while verifică condiția la început (se poate executa de 0 ori), iar do-while o verifică la final (se execută cel puțin 1 dată).
