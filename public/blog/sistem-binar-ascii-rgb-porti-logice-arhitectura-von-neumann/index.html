Răspuns Rapid (TL;DR)

Orice calculator înțelege doar două stări electrice: 0 (Oprit / 0V) și 1 (Pornit / +5V), numite biți. Grupați câte 8 biți formează 1 Byte (0–255), suficient pentru o literă ASCII sau o componentă de culoare RGB. 1. Sistemul Binar (baza 2) & Hexazecimal (baza 16): Metoda puterilor lui 2

Noi numărăm în baza 10 pentru că avem 10 degete, deci pozițiile reprezintă puterile lui 10 (1, 10, 100...). Calculatorul are doar 2 stări pe un fir electric (0 și 1), deci fiecare poziție de la dreapta la stânga valorează o putere a lui 2: 1, 2, 4, 8, 16, 32, 64, 128.

Pentru a transforma un număr de la 0 la 255 în binar pe 8 biți fără să greșești vreodată: pornești de la 128 spre 1 și pui „1” ori de câte ori puterea încape în restul rămas, apoi scazi!

2. Cum devin biții litere (ASCII / UTF-8) și culori pe ecran (RGB 24 biți)

Odată ce știm să scriem numere între 0 și 255 pe 1 Byte (8 biți), putem atribui fiecărui număr o semnificație prin convenție universală:

În standardul ASCII (7/8 biți), litera mare "A" este codul 65 (01000001 în binar), "B" este 66, iar litera mică "a" este 97 (diferență exactă de 32 = bitul 5!). Cifra "0" ca text este codul 48, nu numărul 0. Pentru diacriticele românești (ă, â, î, ș, ț) și emoji, calculatoarele moderne folosesc UTF-8 / Unicode.

Pentru culori, fiecare pixel de pe monitor are 3 LED-uri microscopice: Roșu (R), Verde (G) și Albastru (B). Fiecare primește 1 Byte (0..255). Combinând 3 Bytes = 24 de biți pe pixel obținem 256 × 256 × 256 = 16.777.216 de culori distincte! De exemplu, #10B981 (verdele ArkyEdu) înseamnă R=16, G=185, B=129.

3. Porțile Logice (AND, OR, NOT, XOR) și Semi-Sumatorul: Cum „gândește” siliciul

În interiorul unui procesor modern miliarde de tranzistori microscopici formează porți logice elementare. Acestea combină biți de intrare A și B și produc un bit de ieșire:

  • Poarta AND (ȘI): Dă 1 doar dacă AMBELE intrări sunt 1 (altfel 0). Esențială pentru măști de biți și condiții stricte.
  • Poarta OR (SAU): Dă 1 dacă CEL PUȚIN O intrare este 1.
  • Poarta NOT (NU): Inversează bitul (0 devine 1, iar 1 devine 0).
  • Poarta XOR (SAU Exclusiv): Dă 1 doar când intrările sunt DIFERITE (una 0 și una 1). Este inima adunării binare și a criptării!
  • Semi-Sumatorul (Half Adder): Combinând doar o poartă XOR (pentru bitul de Sumă S = A XOR B) și o poartă AND (pentru bitul de Transport Carry C = A AND B), procesorul poate aduna deja biți!

4. Arhitectura Von Neumann & Ciclul CPU: Fetch → Decode → Execute

În 1945, matematicianul John von Neumann a formulat arhitectura pe care se bazează aproape toate calculatoarele actuale: atât datele, cât și instrucțiunile programului stau împreună în aceeași memorie RAM, iar Unitatea Centrală de Prelucrare (CPU) le execută într-un ciclu continuu:

  1. FETCH (Preluare): Registrul PC (Program Counter) indică adresa din RAM a următoarei instrucțiuni. CPU o copiază în registrul IR (Instruction Register) și incrementează PC.
  2. DECODE (Decodare): Unitatea de Comandă și Control (UCC) interpretează codul operației (ex: LOAD, ADD, STORE, JZ) și pregătește adresa operandului în MAR (Memory Address Register).
  3. EXECUTE (Execuție): Unitatea Aritmetică și Logică (UAL / ALU) efectuează calculul folosind acumulatorul ACC și actualizează indicatorul ZERO_FLAG (pentru decizii if/while).
  4. REPEAT: Ciclul reîncepe de miliarde de ori pe secundă (un procesor la 3,5 GHz execută 3,5 miliarde de tacturi pe secundă!).

5. Operatori pe biți în C++ (&, |, ^, <<, >>) folosiți la concursuri și robotică

În C++ și în programarea microcontrollerelor Arduino, operatorii pe biți lucrează direct pe reprezentarea binară a numerelor întregi, fiind de câteva ori mai rapizi decât operațiile aritmetice clasice:

Trucuri rapide pe biți în C++ pentru gimnaziu și liceu
// 1. Verificare par / impar fara modulo % (ultimul bit este 1 => impar!)
if (n & 1) cout << "Impar"; else cout << "Par";

// 2. Inmultire / impartire instantanee cu puteri ale lui 2 (bit-shift)
int dublu = n << 1;     // echivalent cu n * 2
int patruOri = n << 2;  // echivalent cu n * 4
int jumatate = n >> 1;  // echivalent cu n / 2 (pentru n >= 0)

// 3. Interschimbare fara variabila auxiliara folosind XOR:
a ^= b; b ^= a; a ^= b; // (in practica la clasa folosim aux, mai clar!)

// 4. Verificarea bitului k (0-indexed) sau activarea unui pin Arduino:
bool bitK = (n >> k) & 1;
Deplasarea la stânga cu k poziții (<< k) înmulțește numărul cu 2^k, iar deplasarea la dreapta (>> k) îl împarte la 2^k.

❓ Întrebări frecvente (FAQ)

Care este diferența dintre bit (b) și Byte / octet (B)?
Un bit (b mic) este unitatea elementară cu o singură valoare: 0 sau 1. Un Byte (B mare) sau octet este format din 8 biți grupați și poate reprezenta 2^8 = 256 de combinații distincte (0..255).
De ce este 1 Kilobyte egal cu 1.024 Bytes și nu 1.000?
Pentru că arhitectura calculatoarelor este bazată pe puterile lui 2, iar 2^10 = 1.024 este cea mai apropiată putere a lui 2 de 1.000.
Ce face mai exact poarta XOR și de ce e specială?
Poarta XOR returnează 1 doar când cele două intrări sunt diferite (0 și 1 sau 1 și 0). Este singura poartă care calculează suma binară a doi biți fără transport, stând la baza unității aritmetice din CPU.
Care sunt cele 3 registre de bază din simulatorul Von Neumann?
PC (Program Counter — adresa instrucțiunii curente), IR (Instruction Register — codul instrucțiunii decodate) și ACC (Accumulator — registrul unde se calculează rezultatele ALU).
