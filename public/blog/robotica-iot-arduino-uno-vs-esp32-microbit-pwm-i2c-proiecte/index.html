2. PWM (Pulse Width Modulation) și I2C explicat pe înțelesul tuturor

Un microcontroller este digital — pinii lui pot scoate doar 0V (LOW) sau 5V/3.3V (HIGH), niciodată „2.5V reali”. Cum reglăm atunci intensitatea unui LED sau viteza unui motor? Prin PWM: aprindem și stingem pinul de ~490–980 de ori pe secundă (cu funcția analogWrite(pin, 0..255)), modificând factorul de umplere (Duty Cycle)!

Iar când vrem să conectăm un ecran LCD 16x2 sau un display OLED fără să ocupăm 10 pini, folosim protocolul I2C (Inter-Integrated Circuit): toți senzorii compatibili se leagă în paralel pe DOAR două fire de date — SDA (Date) și SCL (Ceas), fiecare dispozitiv având propria adresă hexazecimală (ex: 0x27 sau 0x3C).

3. Exemplu complet: Iluminat stradal inteligent (LDR + PWM + millis())

Acest program combină un fotorezistor LDR (citit analogic pe A0), un LED stradal dimabil prin PWM (pinul ~9, marcat cu tilda ~) și temporizare non-blocantă cu millis() pentru a nu bloca restul senzorilor din Smart City:

Iluminat adaptiv Smart City cu PWM și millis() (C++ Arduino)
const int PIN_LDR = A0;
const int PIN_LED_PWM = 9; // Pin cu ~ (suportă PWM)
unsigned long ultimCheck = 0;

void setup() {
  pinMode(PIN_LED_PWM, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  if (millis() - ultimCheck >= 200) {
    ultimCheck = millis();
    int lumina = analogRead(PIN_LDR); // 0 (întuneric) .. 1023 (soare puternic)
    // Inversăm: cu cât e mai întuneric, cu atât LED-ul luminează mai tare
    int puterePWM = map(lumina, 0, 1023, 255, 0);
    puterePWM = constrain(puterePWM, 0, 255);
    analogWrite(PIN_LED_PWM, puterePWM);
  }
}
Atenție: pe Arduino Uno doar pinii marcați cu ~ (3, 5, 6, 9, 10, 11) suportă PWM hardware prin analogWrite()!

4. Top 7 greșeli fatale pe breadboard care ard LED-uri, senzori sau placa

Înainte să bagi cablul USB în calculator, verifică aceste 7 reguli de aur din laborator:

  1. LED conectat fără rezistor de 220 Ω–330 Ω în serie → curentul urcă brusc și arde LED-ul sau pinul microcontrollerului.
  2. Semnal de 5V (ex: ECHO de la HC-SR04) băgat direct într-un pin de ESP32 (3.3V) → necesită divizor rezistiv (ex: 1 kΩ + 2 kΩ).
  3. Alimentarea unui servomotor mare sau motor DC direct din pinul de 5V al USB-ului / Arduino → provoacă resetări instantanee sau arde regulatorul; folosește sursă externă + GND comun.
  4. Uitarea firului comun de masă (GND): dacă ai o baterie externă pentru motoare, minusul bateriei TREBUIE legat la GND-ul plăcii Arduino/ESP32.
  5. Montarea inversă a LED-ului (piciorul lung + anod la GND) sau inversarea polarității pe condensatori electrolitici.
  6. Scurtcircuit accidental pe șinele + / − ale breadboard-ului (pini îndoiți care se ating sub modul).
  7. Folosirea pinilor 0 și 1 (RX/TX) pe Arduino Uno pentru LED-uri/butoane → blochează încărcarea codului prin USB și Serial Monitor.
Tester de siguranță în 5 secunde

Dacă simți miros slab de plastic încins sau placa devine fierbinte la atingere, scoate IMEDIAT cablul USB și verifică alimentarea 5V/GND cu un multimetru înainte de a o reconecta!

✅ Checklist înainte de alimentarea oricărui montaj IoT

  • Fiecare LED are rezistor în serie de 220 Ω–330 Ω (Legea lui Ohm: R = (V_sursă − V_LED) / I).
  • Toate sursele de alimentare (USB, baterii motoare) împart același fir de masă (GND comun).
  • Dacă folosesc ESP32 (3.3V), niciun senzor de 5V nu intră direct pe GPIO fără divizor de tensiune.
  • Am testat logica algoritmului întâi în Arkedo Smart City (/oras/) și în misiunile Arduino.

❓ Întrebări frecvente (FAQ)

Ce aleg pentru un elev în clasa a VII-a: Arduino Uno sau ESP32?
Începe cu Arduino Uno (sau kit compatibil) pentru că tolerează mai ușor micile erori pe 5V și se aliniază 100% manualelor românești. După ce stăpânești senzorii și millis(), treci la ESP32 pentru proiecte Wi-Fi/IoT.
De ce are ESP32 nevoie de atenție la tensiunea de 3.3V?
Logica internă a cipului ESP32 funcționează la 3.3V. Aplicarea unei tensiuni de 5V de la un senzor clasic direct pe un pin GPIO al ESP32 poate distruge definitiv pinul respectiv.
Pe ce pini ai plăcii Arduino Uno funcționează analogWrite() pentru PWM?
Pe Arduino Uno R3, PWM hardware este disponibil exclusiv pe cei 6 pini marcați cu tilda (~): 3, 5, 6, 9, 10 și 11.
Cum leg un ecran LCD cu adaptor I2C la Arduino Uno?
Doar 4 fire: VCC la 5V, GND la GND, SDA la pinul A4 și SCL la pinul A5.
