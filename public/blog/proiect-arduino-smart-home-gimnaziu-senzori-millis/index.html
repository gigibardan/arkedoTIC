1. Harta plăcii Arduino Uno: Pini digitali, analogici A0–A5, PWM (~) și rezistorul de 220 Ω

Arduino Uno lucrează la 5V și citește mediul înconjurător prin două tipuri principale de pini: pini digitali (D0–D13, care știu doar HIGH/5V sau LOW/0V) și pini analogici (A0–A5, care măsoară valori continue între 0 și 1023 cu ajutorul convertorului ADC pe 10 biți). Pinii marcați cu tildă (~: 3, 5, 6, 9, 10, 11) pot genera semnal PWM pentru a regla intensitatea unui LED sau unghiul unui servomotor SG90.

Regulă critică de hardware (Legea lui Ohm, I = U / R): Nu conecta niciodată un LED direct între pinul 5V și GND fără un rezistor în serie (de obicei 220 Ω – 330 Ω)! Fără rezistor, curentul depășește limita de 40 mA a pinului Arduino și arde atât LED-ul, cât și microcontrollerul.

2. Greșeala #1 a începătorilor: delay() blochează tot sistemul vs. Multitasking cu millis()

Când scrii delay(5000); ca să ții bariera deschisă 5 secunde, procesorul plăcii Arduino „doarme” complet: dacă în acele 5 secunde apare o scurgere de gaz la senzorul MQ-2, alarma NU pornește până nu expiră pauza! Într-un sistem real Smart Home, așa ceva este inacceptabil.

Soluția profesionistă este funcția millis(), care returnează numărul de milisecunde trecute de la pornirea plăcii. Salvând momentul ultimei acțiuni (unsigned long timpAnterior = 0;), putem verifica non-blocant dacă a trecut intervalul dorit, în timp ce senzorul de gaz este citit de mii de ori pe secundă!

Schemă cod C++ Arduino cu millis() pentru Iluminat + Alertă Gaz simultane
const int PIN_LDR = A0;
const int PIN_GAZ = A1;
const int PIN_LED_STRADA = 6; // Pin PWM (~)
const int PIN_BUZZER = 8;

unsigned long ultimulControl = 0;
const unsigned long INTERVAL_LUMINA = 250; // verifica lumina la 250 ms fara blocare

void setup() {
  pinMode(PIN_LED_STRADA, OUTPUT);
  pinMode(PIN_BUZZER, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  unsigned long acum = millis();

  // 1. Prioritate maxima NON-BLOCANTA: verificare instantanee gaz MQ-2
  int nivelGaz = analogRead(PIN_GAZ);
  if (nivelGaz > 450) {
    tone(PIN_BUZZER, 1200);
  } else {
    noTone(PIN_BUZZER);
  }

  // 2. Sarcina periodica cu millis() (fara delay!) pentru iluminat inteligent PWM
  if (acum - ultimulControl >= INTERVAL_LUMINA) {
    ultimulControl = acum;
    int lumina = analogRead(PIN_LDR);
    // Daca e intuneric (lumina < 400), crestem intensitatea LED-ului pe PWM
    int pwm = (lumina < 400) ? map(lumina, 0, 400, 255, 60) : 0;
    analogWrite(PIN_LED_STRADA, pwm);
  }
}
Observă utilizarea lui unsigned long pentru millis() și absența completă a funcției delay().

3. Cum depanezi rapid un circuit Arduino care nu răspunde

La proiectele practice din laborator, 80% din probleme sunt de cablare pe breadboard sau de selecție din Arduino IDE, nu de logică:

  1. Verifică masa comună (GND): Toți senzorii, LED-urile și eventualele baterii externe ale motoarelor trebuie să împartă același GND cu placa Arduino!
  2. Verifică polaritatea LED-ului: Piciorușul lung (Anod +) merge spre rezistor și pinul digital; piciorușul scurt/partea teșită (Catod -) merge spre GND.
  3. Folosește Serial.begin(9600); și Serial Monitor pentru a afișa valorile brute citite de la senzori (ex: ca să afli pragul real al senzorului LDR din sala de clasă).
  4. Dacă LCD 1602 I2C se aprinde albastru dar nu afișează text, rotește ușor potențiometrul albastru de contrast de pe spatele modulului I2C și verifică adresa (0x27 sau 0x3F).
Atenție la alimentarea motoarelor

Nu alimenta motoare DC mari direct din pinii digitali ai plăcii Arduino! Folosește o punte H (de exemplu L298N) cu alimentare dedicată și GND comun.

✅ Checklist înainte de demonstrația Smart Home la clasă

  • Fiecare LED este protejat cu un rezistor în serie de 220 Ω–330 Ω.
  • Toate firele de masă (GND) sunt conectate în aceeași linie comună pe breadboard.
  • Am folosit millis() pentru temporizări astfel încât senzorii de urgență (MQ-2, PIR) să nu fie blocați de delay().
  • Am testat pragurile senzorilor în Serial Monitor la lumina reală din încăpere.

❓ Întrebări frecvente (FAQ)

De ce trebuie să pun un rezistor de 220 Ω în serie cu fiecare LED pe Arduino?
Un LED consumă în jur de 2V și suportă ~20 mA. Pinul Arduino scoate 5V; fără rezistor, conform Legii lui Ohm, curentul devine mult prea mare și arde instantaneu LED-ul sau pinul microcontrollerului.
Care este diferența dintre pinii digitali și pinii analogici A0–A5?
Pinii digitali citesc sau trimit doar două stări (HIGH = 5V, LOW = 0V), fiind perfecți pentru butoane, PIR sau relee. Pinii analogici A0–A5 citesc o gamă întreagă de valori între 0 și 1023, necesară pentru fotorezistoare LDR, senzori de temperatură sau MQ-2.
De ce este recomandat millis() în locul lui delay() la proiectul Smart Home?
Funcția delay() oprește complet execuția programului pe durata pauzei, făcând Arduino surd la senzori critici (cum ar fi alarma de gaz MQ-2). Cu millis(), cronometrezi non-blocant și toate subsistemele funcționează simultan.
Cum calculez distanța cu senzorul ultrasonic HC-SR04?
Trimiți un impuls de 10 microsecunde pe pinul TRIG, măsori cu pulseIn(ECHO, HIGH) durata întoarcerii ecoului și calculezi distanța în centimetri cu formula: distanta = durata * 0.034 / 2.

Arduino UNO și Structura Schiței (setup & loop) →
Arduino UNO este o placă electronică open-source cu microcontroler (ATmega328P) folosită la școală pentru robotică și proiecte Smart Home. Fiecare program Arduino (numit sketch) are două funcții obligatorii: setup() care rulează o singură dată la pornire și loop() care se repetă la infinit.
Pini Digitali, Analogici (ADC) și PWM (~) pe Arduino →
Pinii digitali (0–13) lucrează doar cu două stări binare: HIGH (5V / 1) sau LOW (0V / 0). Pinii analogici (A0–A5) măsoară tensiuni continue de la senzori transformându-le în valori de la 0 la 1023, iar pinii PWM (~) simulează ieșiri intermediare între 0 și 255.
Rezistor de Protecție & Legea lui Ohm (U = I · R) →
Rezistorul este componenta electronică care limitează curentul electric într-un circuit, prevenind arderea LED-urilor și a pinilor Arduino. Conform Legii lui Ohm (U = R · I), pentru un LED conectat la 5V este necesar un rezistor în serie de aproximativ 220 Ω – 330 Ω.
Senzor Ultrasonic HC-SR04 (Măsurarea Distanței cu Ultrasunete) →
HC-SR04 este un senzor cu 4 pini (VCC, Trig, Echo, GND) care măsoară distanța până la un obstacol (2 cm – 400 cm) emițând un impuls ultrasonic pe pinul Trig și cronometrând pe pinul Echo în câte microsecunde se întoarce ecoul.
Senzori Smart Home: PIR (Mișcare), MQ-2 (Gaz/Fum) și DHT11 →
Proiectele școlare de casă inteligentă (Smart Home) folosesc trei senzori esențiali: PIR HC-SR501 (detectează mișcare prin infraroșu pasiv), MQ-2 (detectează scurgeri de gaz și fum prin valoare analogică) și DHT11 (măsoară temperatura și umiditatea).
Multitasking în Arduino: Funcția millis() vs. delay() →
Funcția delay(ms) îngheață complet procesorul Arduino pe durata așteptării, ratând apăsările de butoane și senzorii. Funcția millis() returnează milisecundele trecute de la pornirea plăcii, permițând execuția simultană (non-blocking) a mai multor sarcini.
