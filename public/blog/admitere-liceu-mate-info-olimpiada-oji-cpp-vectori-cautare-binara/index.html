Pregătire OJI & Admitere Mate-Info (VII–VIII): Complexitate O(n)/O(log n), Primalitate O(√n), Vectori de Frecvență & Căutare Binară în C++

1. Cum estimezi complexitatea în timp înainte să scrii prima linie de cod

Evaluatoarele automate (inclusiv Arena Olimpiada TIC din ArkyEdu și PbInfo/OJI) rulează în jur de 10^7 – 10^8 operații elementare pe secundă. Înainte să alegi algoritmul, uită-te la restricția lui N din enunț!

Ghid rapid: Ce complexitate maximă este permisă în funcție de valoarea lui N
Restricție N din enunțComplexitate țintăTehnică tipică în C++Exemplu algoritm
N ≤ 1.000O(N²)Două bucle for imbricateBubble Sort, Selection Sort, perechi (i, j)
N ≤ 100.000O(N log N) sau O(N)Sortare eficientă, Căutare Binară, FrecvențăCăutare binară pe M interogări, Ciurul lui Eratostene
N ≤ 1.000.000O(N)O singură parcurgere liniarăMinim/Maxim, Vector de frecvență, Sume parțiale
N ≤ 10⁹ sau 10¹²O(√N) sau O(log N) sau O(1)Matematică, divizori până la √N, formula lui GaussTest primalitate d*d <= n, CMMDC Euclid, sumă 1..N
Atenție la capcana i*i <= n cu int pe 32 de biți!

Dacă n se apropie de 2 miliarde (2·10^9) și verifici primalitatea cu for (int d = 3; d * d <= n; d += 2), produsul d * d poate depăși limita lui int (2.147.483.647) și produce overflow! Folosește 1LL * d * d <= n sau tipul long long.

2. Testul de primalitate în O(√N) și Ciurul lui Eratostene pentru intervale mari

Un elev începător verifică dacă n este prim împărțind la toți divizorii de la 2 la n - 1 — ceea ce face 1.000.000 de pași pentru n = 10^6. Însă orice divizor mai mare decât √n are un „pereche” mai mic sau egal cu √n! Prin urmare, este suficient să verificăm până la d*d <= n (doar ~1.000 de pași!).

Dacă problema cere să verifici 100.000 de numere diferite până la 1.000.000, precalcularea cu Ciurul lui Eratostene (vector boolean ciur[MAX]) îți dă răspunsul pentru fiecare număr în O(1) instantaneu!

Șablon C++: Funcție optimă estePrim(n) în O(√n) + Ciurul lui Eratostene
bool estePrim(long long n) {
    if (n < 2) return false;
    if (n == 2) return true;
    if (n % 2 == 0) return false;
    for (long long d = 3; d * d <= n; d += 2) {
        if (n % d == 0) return false;
    }
    return true;
}

// Pentru interogari multiple (ex: prime pana la 100000):
const int MAXV = 100000;
bool compus[MAXV + 1]; // implicit false (global)
void construiesteCiur() {
    compus[0] = compus[1] = true;
    for (int i = 2; i * i <= MAXV; i++) {
        if (!compus[i]) {
            for (int j = i * i; j <= MAXV; j += i) {
                compus[j] = true;
            }
        }
    }
}
Observă că al doilea for din Ciur pornește direct de la i * i, economisind operații redundante.

3. Vectori de frecvență (Counting Sort): Cum înlocuiești 2 bucle cu 1 singură parcurgere

Una dintre cele mai des întâlnite cerințe la clasa a VIII-a și OJI este: „Se dau N numere cuprinse între 0 și 1.000 (sau cifre 0..9). Să se afișeze în ordine crescătoare / cel mai frecvent element.”

În loc să sortezi vectorul în O(N²) sau să numeri pentru fiecare element de câte ori apare cu două bucle, folosești valoarea citită x direct ca INDICE într-un vector de frecvență global: fr[x]++. Astfel obții soluția în timp liniar O(N + VAL_MAX)!

Exemplu C++: Cea mai frecventă cifră / valoare cu vector de frecvență
#include <iostream>
using namespace std;

int fr[1001]; // declarat global => toate elementele sunt 0 automat!

int main() {
    int n, x;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> x;
        if (x >= 0 && x <= 1000) fr[x]++;
    }
    int bestVal = 0, maxAparitii = -1;
    for (int v = 0; v <= 1000; v++) {
        if (fr[v] > maxAparitii) {
            maxAparitii = fr[v];
            bestVal = v;
        }
    }
    cout << bestVal << " apare de " << maxAparitii << " ori\n";
    return 0;
}
Declararea vectorului mare în afara funcției main() îl inițializează cu 0 și previne eroarea Stack Overflow.

4. Căutarea Binară în O(log N): Cele 3 reguli ca să nu blochezi niciodată bucla while

Căutarea binară funcționează EXCLUSIV pe un șir ordonat (crescător sau descrescător) și înjumătățește spațiul de căutare la fiecare pas. Pentru 1.000.000 de elemente, găsește răspunsul în cel mult 20 de comparații!

Majoritatea bug-urilor apar atunci când elevii scriu left = mid sau right = mid în loc de mid + 1 / mid - 1, lăsând intervalul [mid, mid + 1] blocat la infinit.

Șablon standard C++ pentru Căutare Binară exactă + Prima apariție (Lower Bound)
// Returneaza pozitia lui x in vectorul v[1..n] sortat crescator, sau -1 daca lipseste
int cautareBinara(int v[], int n, int x) {
    int st = 1, dr = n;
    while (st <= dr) {
        int mij = st + (dr - st) / 2; // previne overflow fata de (st + dr) / 2
        if (v[mij] == x) return mij;
        if (v[mij] < x) st = mij + 1;
        else dr = mij - 1;
    }
    return -1;
}

// Prima pozitie cu v[poz] >= x (utila la probleme de optimizare / admitere)
int primaPozitie(int v[], int n, int x) {
    int st = 1, dr = n, ans = -1;
    while (st <= dr) {
        int mij = st + (dr - st) / 2;
        if (v[mij] >= x) {
            ans = mij;
            dr = mij - 1; // continuam sa cautam mai la stanga!
        } else {
            st = mij + 1;
        }
    }
    return ans;
}

5. Strategia celor 5 pași în sala de concurs & Debugging în Visual Trace

Chiar și algoritmii perfecți pot pierde puncte la teste de margine (N = 1, număr = 0, toate elementele egale, sume care depășesc int). Aplică această rutină disciplinată la fiecare problemă:

  1. Citește restricțiile cu atenție: verifică tipul maxim (dacă suma poate trece de 2·10^9, folosește long long din start) și dacă fișierele cer cin/cout sau ifstream/ofstream.
  2. Verifică cazurile limită pe hârtie: ce face codul tău pentru n = 0, n = 1, valoare minimă sau toate numerele identice?
  3. Declararea vectorilor: declară vectorii mari (ex: int v[100005];) global, deasupra lui int main(), cu 5–10 poziții în plus față de maximul din enunț.
  4. Urmărește primele 2–3 iterații pas cu pas (Trace Table): notează valorile lui i, st, dr, s pe hârtie sau rulează-le în Debugger-ul C++ Visual Trace.
  5. Nu lăsa instrucțiuni de debug sau mesaje text necerute (gen "Introduceti n: ") în cout — evaluatorul compară strict numerele din ieșire!

✅ Checklist înainte să trimiți soluția C++ la OJI / Evaluare

  • Am verificat dacă sumele sau produsele depășesc tipul int și am folosit long long unde este nevoie.
  • Vectorii cu peste 1.000 de elemente sunt declarați global, nu în interiorul lui main().
  • Nu există mesaje extra în cout (fără „Dati n=” sau pause/system) și fiecare caz limită (0, 1, duplicat) a fost testat.
  • Complexitatea algoritmului încape confortabil sub 10^7 operații pentru valoarea maximă a lui N.

❓ Întrebări frecvente (FAQ)

De ce este recomandat să declari vectorii mari global, în afara funcției main()?
Memoria stivă (stack) alocată în interiorul lui main() este limitată (uneori la doar 1–8 MB), în timp ce variabilele globale stau în zona statică de date (zeci/sute de MB) și sunt inițializate automat cu 0 de compilator.
Când folosesc vector de frecvență și când sortez vectorul clasic?
Folosești vector de frecvență când valorile numerelor sunt mici și pozitive (de ex. 0..1.000.000). Dacă valorile pot fi până la 10^9 sau negative, sortezi vectorul.
De ce se scrie mij = st + (dr - st) / 2 în loc de (st + dr) / 2?
Dacă st și dr sunt apropiate de 1,5 miliarde, suma st + dr depășește limita lui int și devine negativă (overflow). Scăderea (dr - st) evită complet această eroare.
