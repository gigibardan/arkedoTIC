Grade 5 ICT Worksheet: PC Architecture, RAM vs ROM & Data Storage Units

Quick Summary & Key Points:

This worksheet covers 5 core items (90 pts + 10 free pts): volatile RAM vs non-volatile ROM, Input/Output peripheral classification, bit-to-GB conversions (1 Byte = 8 bits), CPU role, and the 20-20-20 eye safety rule.

Theory Snapshot: Quick recap: CPU executes instructions (measured in GHz); RAM is fast temporary memory erased on power-off; ROM holds boot firmware; SSD/HDD keeps files permanently. 1 Byte = 8 bits, 1 KB = 1,024 Bytes.

Solve & Auto-Grade (1–10)
1. Part I · 1 (18p)

Which memory type is VOLATILE (loses all stored data when power is turned off)?

  • A) ROM Memory (BIOS/UEFI)
  • B) RAM Memory
  • C) NVMe SSD Drive
  • D) USB Flash Drive

Answer & Explanation: B) RAM Memory — RAM (Random Access Memory) holds active workspace data temporarily and clears as soon as power stops.

2. Part I · 2 (18p)

Which group contains ONLY Output (O) peripheral devices?

  • A) Keyboard, Mouse, Microphone
  • B) Monitor, Printer, Headphones
  • C) Scanner, Webcam, Speakers
  • D) Touchscreen, Joystick, Printer

Answer & Explanation: B) Monitor, Printer, Headphones — Monitors, printers, and headphones send data out from the computer to the user. A touchscreen is dual I/O.

3. Part II · 1 (18p)

How many bits are in a text file measuring exactly 4 Bytes? Enter only the number.

Answer & Explanation: 32 — 1 Byte = 8 bits ⇒ 4 Bytes × 8 bits = 32 bits.

4. Part II · 2 (18p)

True or False: The Central Processing Unit (CPU) contains the Arithmetic Logic Unit (ALU) and the Control Unit (CU).

  • A) True
  • B) False

Answer & Explanation: A) True — True. The ALU performs arithmetic/logic math while the Control Unit orchestrates instruction execution.

5. Part III (18p)

A photo takes 2,048 KB. How many MB (binary Megabytes, 1 MB = 1,024 KB) does it use?

  • A) 0.5 MB
  • B) 2 MB
  • C) 4 MB
  • D) 20 MB

Answer & Explanation: B) 2 MB — 2,048 KB / 1,024 = 2 MB.
