Grade 6 ICT Worksheet: If-Else Decisions, Boolean Operators & Conditional Loops in Scratch

Quick Summary & Key Points:

Master If-Then-Else branching, compound AND/OR/NOT Boolean expressions, and tracing Scratch "repeat until <condition>" loops where execution stops as soon as the condition becomes true.

Theory Snapshot: In Scratch, "repeat until <condition>" STOPS the instant the condition turns TRUE (whereas C++ `while` keeps running while true).

Solve & Auto-Grade (1–10)
1. Part I · 1 (18p)

Let Score = 12 and Lives = 0. What is the result of: (Score > 10) AND (Lives > 0)?

  • A) True
  • B) False
  • C) 12
  • D) Error

Answer & Explanation: B) False — Score > 10 is True, but Lives > 0 is False. AND requires BOTH sides to be True ⇒ False.

2. Part I · 2 (18p)

For the same values (Score = 12, Lives = 0), what is: (Score > 10) OR (Lives > 0)?

  • A) True
  • B) False
  • C) 0
  • D) Undefined

Answer & Explanation: A) True — OR evaluates to True whenever at least one condition is True (12 > 10 is True).

3. Part II · 1 (18p)

What is the final value of variable `n` after running the Scratch blocks below?

setează [n] la (2)
repetă până când <(n) > (10)>
    modifică [n] cu (3)
sfârșit

Answer & Explanation: 11 — n steps 2 → 5 → 8 → 11. At n = 11, 11 > 10 becomes True so "repeat until" exits!

4. Part II · 2 (18p)

True or False: In an "if <condition> then [A] else [B]" block, both branch [A] and branch [B] can run during the same check.

  • A) True
  • B) False

Answer & Explanation: B) False — False. Branches are mutually exclusive: only A runs if True, or only B if False.

5. Part III (18p)

You want a sprite to say "You win!" the instant it touches the green flag target. Which loop structure fits best?

  • A) forever [ if <touching [Flag]?> then say "You win!" ]
  • B) wait 100 seconds
  • C) delete all clones
  • D) hide variable Score

Answer & Explanation: A) forever [ if <touching [Flag]?> then say "You win!" ] — Wrapping `if <touching Flag?>` inside a `forever` loop continuously checks for collision.
