Grade 5 ICT Worksheet: Operating Systems, Folder Trees & File Extensions

Quick Summary & Key Points:

Covers OS vs app software, Windows folder tree paths (C:\Folder\File.ext), forbidden filename characters (\ / : * ? " < > |), and common file extensions (.docx, .pdf, .png, .mp3, .exe).

Theory Snapshot: Every file uses the pattern Name.extension (e.g., essay.pdf). Full paths start at the root drive (D:\Grade5\ICT\photo.png). Standard Delete moves to Recycle Bin; Shift+Delete skips it.

Solve & Auto-Grade (1–10)
1. Part I · 1 (18p)

Which option is an OPERATING SYSTEM (not an end-user application)?

  • A) Microsoft Word
  • B) Windows 11 / Linux Ubuntu
  • C) Google Chrome
  • D) Paint 3D

Answer & Explanation: B) Windows 11 / Linux Ubuntu — Windows 11 and Linux Ubuntu manage hardware resources and host all applications.

2. Part I · 2 (18p)

Which file extension identifies a portable fixed-layout document ready for printing?

  • A) .mp3
  • B) .pdf
  • C) .exe
  • D) .wav

Answer & Explanation: B) .pdf — .pdf (Portable Document Format) preserves exact layout and fonts across devices.

3. Part II · 1 (18p)

Given the path D:\School\Informatics\project.docx, write the exact name of the folder containing the file.

Answer & Explanation: Informatica — In D:\School\Informatics\project.docx, the immediate parent folder before the filename is Informatics (or Informatica).

4. Part II · 2 (18p)

True or False: Windows allows naming a file "Homework?.txt" using a question mark.

  • A) True
  • B) False

Answer & Explanation: B) False — False. Characters \ / : * ? " < > | are reserved by Windows and disallowed in filenames.

5. Part III (18p)

Which keyboard shortcut copies a selected file to the Clipboard without removing the original?

  • A) Ctrl + X
  • B) Ctrl + C
  • C) Ctrl + V
  • D) Shift + Delete

Answer & Explanation: B) Ctrl + C — Ctrl + C = Copy; Ctrl + X = Cut; Ctrl + V = Paste.
