Grade 8 Web Design Exam with Rubric: Semantic HTML5, CSS & HTTPS/DNS (100 pts)

Quick Summary & Key Points:

Covers modern Web Design foundations (100 pts): semantic HTML5 containers (`<header>`, `<nav>`, `<main>`, `<footer>`), `<img alt>` accessibility, CSS layout styling, DNS domain resolution, and HTTPS port 443.

Theory Snapshot: HTML5 provides semantic structure; CSS styles colors, typography, and Flexbox layout. DNS translates human domain names into server IP addresses.

Solve & Auto-Grade (1–10)
1. Part I · 1 (18p)

Which semantic HTML5 tag wraps the unique MAIN content of a web page?

  • A) <head>
  • B) <main>
  • C) <style>
  • D) <br>

Answer & Explanation: B) <main> — `<main>` holds the primary page body (separate from `<header>`, `<nav>`, and `<footer>`), whereas `<head>` holds page metadata.

2. Part I · 2 (18p)

What is the purpose of the `alt="..."` attribute inside `<img src="robot.png" alt="Arduino Robot">`?

  • A) Sets image height in pixels
  • B) Provides accessible screen-reader description and fallback text if the image fails to load
  • C) Converts the image into a PDF
  • D) Opens a new browser tab

Answer & Explanation: B) Provides accessible screen-reader description and fallback text if the image fails to load — The `alt` attribute powers screen-reader accessibility, fallback rendering, and image SEO.

3. Part II · 1 (18p)

What 3-letter Internet system translates domain names like `www.arkyedu.com` into numeric IP addresses?

Answer & Explanation: DNS — DNS = Domain Name System.

4. Part II · 2 (18p)

True or False: The CSS rule `display: flex;` enables responsive row or column card layouts cleanly.

  • A) True
  • B) False

Answer & Explanation: A) True — True. CSS Flexbox (`display: flex;`) provides clean one-dimensional responsive alignment.

5. Part III (18p)

Which snippet creates a valid HTML hyperlink pointing to `https://www.arkyedu.com`?

  • A) <link url="https://www.arkyedu.com">ArkyEdu</link>
  • B) <a href="https://www.arkyedu.com">ArkyEdu</a>
  • C) <img href="https://www.arkyedu.com">ArkyEdu</img>
  • D) <p src="https://www.arkyedu.com">ArkyEdu</p>

Answer & Explanation: B) <a href="https://www.arkyedu.com">ArkyEdu</a> — Clickable links always use the anchor element `<a>` with the `href` attribute.
