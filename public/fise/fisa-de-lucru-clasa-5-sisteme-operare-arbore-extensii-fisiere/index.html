Fișă de Lucru Clasa a V-a: Sisteme de Operare, Arbore Directoare & Extensii Fișiere

Rezumat Direct & Punctaj:

Fișa exersează diferența dintre sistem de operare și aplicație, scrierea corectă a căilor ierarhice în Windows (C:\Folder\Fisier.ext), caracterele rezervate interzise (\ / : * ? " < > |) și asocierea extensiilor (.docx, .png, .mp3, .exe, .pdf).

Sinteză Teorie: Un fișier are forma Nume.extensie (ex: referat.pdf). Calea completă pornește de la partiția rădăcină (ex: D:\Clasa5\TIC\poza.png). Ștergerea obișnuită (Delete) mută în Recycle Bin; Shift+Delete șterge direct.

Rezolvă Online cu Notă Automată 1–10
1. Subiectul I · 1 (18p)

Care dintre următoarele variante reprezintă un SISTEM DE OPERARE (nu o simplă aplicație)?

  • A) Microsoft Word
  • B) Windows 11 / Linux Ubuntu
  • C) Google Chrome
  • D) Paint 3D

Rezolvare & Barem: B) Windows 11 / Linux Ubuntu — Windows 11 și Linux Ubuntu gestionează resursele hardware și permit rularea tuturor aplicațiilor.

2. Subiectul I · 2 (18p)

Care extensie indică un document portabil cu aspect fix, destinat citirii și tipăririi?

  • A) .mp3
  • B) .pdf
  • C) .exe
  • D) .wav

Rezolvare & Barem: B) .pdf — .pdf (Portable Document Format) păstrează intacte fonturile și paginarea pe orice dispozitiv.

3. Subiectul II · 1 (18p)

Privind calea D:\Scoala\Informatica\proiect.docx, scrie numele exact al subdirectorului în care se află fișierul proiect.docx.

Rezolvare & Barem: Informatica — În D:\Scoala\Informatica\proiect.docx, ultimul director dinaintea numelui fișierului este Informatica (sau Informatics).

4. Subiectul II · 2 (18p)

Adevărat sau Fals: În Windows este permis să denumești un fișier „Tema?.txt” folosind semnul întrebării.

  • A) Adevărat
  • B) Fals

Rezolvare & Barem: B) Fals — Fals. Caracterele \ / : * ? " < > | sunt rezervate de sistemul de operare și nu pot apărea în nume.

5. Subiectul III (18p)

Ce combinație de taste copiază fișierul selectat în Clipboard fără să îl șteargă din folderul inițial?

  • A) Ctrl + X
  • B) Ctrl + C
  • C) Ctrl + V
  • D) Shift + Delete

Rezolvare & Barem: B) Ctrl + C — Ctrl + C = Copy (copiere); Ctrl + X = Cut (mutare); Ctrl + V = Paste (lipire).
