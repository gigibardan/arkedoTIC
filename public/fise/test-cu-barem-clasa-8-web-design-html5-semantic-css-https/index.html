Test cu Barem Clasa a VIII-a: Anatomia Paginii Web HTML5 Semantică, CSS Flexbox & HTTPS (100p)

Rezumat Direct & Punctaj:

Test complet HTML5 & Web (100p): rolul etichetelor semantice (`<header>`, `<nav>`, `<main>`, `<footer>`), atributul de accesibilitate `alt` pe `<img>`, diferența dintre structura HTML și stilizarea CSS, plus funcția DNS și HTTPS (port 443).

Sinteză Teorie: HTML5 definește structura și conținutul; CSS definește aspectul (culori, Flexbox, fonturi). DNS funcționează ca „agenda telefonică” a Internetului: traduce `www.arkyedu.com` în adresa IP a serverului.

Rezolvă Online cu Notă Automată 1–10
1. Subiectul I · 1 (18p)

Care etichetă HTML5 semantică trebuie folosită pentru a încadra CONȚINUTUL PRINCIPAL unic al paginii web?

  • A) <head>
  • B) <main>
  • C) <style>
  • D) <br>

Rezolvare & Barem: B) <main> — `<main>` marchează conținutul central al paginii (distinct de `<header>`, `<nav>` și `<footer>`). `<head>` conține metadate invizibile!

2. Subiectul I · 2 (18p)

Ce rol are atributul `alt="..."` în eticheta `<img src="robot.png" alt="Robot Arduino">`?

  • A) Schimbă înălțimea imaginii în pixeli
  • B) Oferă text descriptiv pentru cititoarele de ecran (nevăzători) și apare dacă imaginea nu se încarcă
  • C) Transformă imaginea în fișier PDF
  • D) Deschide un link nou

Rezolvare & Barem: B) Oferă text descriptiv pentru cititoarele de ecran (nevăzători) și apare dacă imaginea nu se încarcă — Atributul `alt` este obligatoriu pentru accesibilitate web, cititoare de ecran și SEO pe imagini.

3. Subiectul II · 1 (18p)

Cum se numește sistemul Internetului (3 litere) care traduce un nume ușor de reținut precum `www.arkyedu.com` în adresa IP numerică a serverului?

Rezolvare & Barem: DNS — DNS = Domain Name System (Sistemul Numelor de Domeniu).

4. Subiectul II · 2 (18p)

Adevărat sau Fals: Proprietatea CSS `display: flex;` permite aranjarea ușoară a cardurilor pe rânduri sau coloane responsive.

  • A) Adevărat
  • B) Fals

Rezolvare & Barem: A) Adevărat — Adevărat. Flexbox (`display: flex;`) este sistemul standard modern de aliniere pe o axă în CSS3.

5. Subiectul III (18p)

Care variantă creează corect un hyperlink HTML care trimite elevul către `https://www.arkyedu.com`?

  • A) <link url="https://www.arkyedu.com">ArkyEdu</link>
  • B) <a href="https://www.arkyedu.com">ArkyEdu</a>
  • C) <img href="https://www.arkyedu.com">ArkyEdu</img>
  • D) <p src="https://www.arkyedu.com">ArkyEdu</p>

Rezolvare & Barem: B) <a href="https://www.arkyedu.com">ArkyEdu</a> — Hyperlink-urile vizibile se definesc cu eticheta ancoră `<a>` și atributul `href="..."`.
