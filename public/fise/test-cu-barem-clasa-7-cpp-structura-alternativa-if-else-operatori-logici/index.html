Test cu Barem C++ Clasa a VII-a: Structura Alternativă `if/else` & Operatori Logici (100p)

Rezumat Direct & Punctaj:

Test complet de 100p (90p + 10p oficiu) pe structura alternativă C++: diferența fatală între `x == 5` și `x = 5`, punct și virgulă pus greșit după `if (...)`, intervale cu `&&`, maximul a 3 numere și verificarea divizibilității.

Sinteză Teorie: În C++, intervalul matematic `10 ≤ x ≤ 99` NU se scrie `10 <= x <= 99` (care e mereu adevărat!), ci `(10 <= x && x <= 99)`! De asemenea, pune mereu `==` pentru comparație și nu pune `;` după `if (...)`.

Rezolvă Online cu Notă Automată 1–10 🔬 Rulează în Trace C++
1. Subiectul I · 1 (18p)

Cum se scrie CORECT în C++ condiția ca numărul `x` să aibă exact 2 cifre pozitive (între 10 și 99 inclusiv)?

  • A) if (10 <= x <= 99)
  • B) if (x >= 10 && x <= 99)
  • C) if (x >= 10 || x <= 99)
  • D) if (x = 10 && 99)

Rezolvare & Barem: B) if (x >= 10 && x <= 99) — Operatorul `&&` (ȘI logic) verifică simultan ambele capete ale intervalului. `||` ar fi adevărat pentru orice număr, iar `10 <= x <= 99` compară 0/1 cu 99!

2. Subiectul I · 2 (18p)

Ce afișează codul: `int a = 3; if (a = 0) cout << "DA"; else cout << "NU";` (atenție la un singur `=`!) ?

  • A) DA / YES
  • B) NU / NO
  • C) 0
  • D) Nimic

Rezolvare & Barem: B) NU / NO — `a = 0` îi atribuie lui `a` valoarea `0` (care în C++ înseamnă Fals!). De aceea se intră pe ramura `else` și se afișează NU / NO.

3. Subiectul II · 1 (18p)

Ce va afișa secvența C++ de mai jos pentru `x = 12` și `y = 5`?

int x = 12, y = 5;
if (x % 3 == 0 && y % 2 == 1) {
    cout << x + y;
} else {
    cout << x - y;
}

Rezolvare & Barem: 17 — `12 % 3 == 0` este Adevărat, iar `5 % 2 == 1` (impar) este Adevărat. Ambele sunt adevărate ⇒ afișează `12 + 5 = 17`.

4. Subiectul II · 2 (18p)

Adevărat sau Fals: Trei numere strict pozitive `a, b, c` pot fi laturile unui triunghi dacă și numai dacă `a + b > c && a + c > b && b + c > a`.

  • A) Adevărat
  • B) Fals

Rezolvare & Barem: A) Adevărat — Adevărat! Aceasta este inegalitatea triunghiului: suma oricăror două laturi trebuie să fie strict mai mare decât a treia.

5. Subiectul III (18p)

Atenție la capcana clasică din C++! Ce afișează secvența de mai jos (observă `;` după `if`)?

int n = 4;
if (n > 10);
    cout << "Salut";

Rezolvare & Barem: Salut — Punct și virgulă `;` imediat după `if (n > 10)` închide instrucțiunea `if` cu un corp gol, deci `cout << "Salut";` se execută NECONDIȚIONAT!
