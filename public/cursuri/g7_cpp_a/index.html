📖 Ghid Didactic & Sinteză Teoretică

Marele Salt: De la Blocuri Vizuale la Cod Textual C++

  • De ce învățăm C++? În anii anteriori am folosit Scratch, unde instrucțiunile se îmbinau ca piesele unui puzzle. C++ este un limbaj profesional extrem de rapid și puternic, folosit în crearea jocurilor 3D, a sistemelor de operare (Windows, Android) și a misiunilor spațiale NASA.
  • Mediul Integrat de Dezvoltare (IDE — Integrated Development Environment): aplicație care reunește într-o singură fereastră: Editorul de text cu evidențiere colorată a codului, Compilatorul (care traduce codul scris de om în cod binar înțeles de procesor) și Depanatorul (Debugger — pentru găsirea erorilor).
  • Code::Blocks este IDE-ul gratuit și standard recomandat de programa școlară pentru învățarea limbajului C++.
  • Etapele rulării unui program: Scriere cod sursă (.cpp) -> Compilare (Build) -> Legare (Link) -> Lansare fișier executabil (.exe).
💡 Sfat de la Profesor: Orice program C++ este sensibil la litere mari și mici (case-sensitive): cuvântul cheie „int” nu poate fi scris „Int” sau „INT”!

Structura Unui Program C++ & Tipuri Fundamentale de Date

  • Anatomia obligatorie a primului program C++:
  • #include — directiva care aduce biblioteca pentru operații de intrare/ieșire.
  • using namespace std; — specifică utilizarea spațiului standard de nume.
  • int main() { ... return 0; } — funcția principală; aici începe execuția oricărui program C++.
  • Fiecare instrucțiune se termină obligatoriu cu caracterul punct și virgulă (;).
  • Ce este o variabilă? O zonă de memorie RAM etichetată cu un nume, în care putem stoca valori care se pot schimba pe parcurs.
  • Tipuri fundamentale de date în C++:
  • • int — numere întregi (ex: -12, 0, 100, 2026).
  • • float / double — numere reale cu zecimale (ex: 3.14, -0.75).
  • • char — un singur caracter alfanumeric, scris între apostrofuri (ex: 'A', '+', '7').
  • • bool — valori logice booleene: true (1 - adevărat) sau false (0 - fals).
💡 Sfat de la Profesor: Apostrof vs Ghilimele în C++: un caracter individual se scrie între apostrofuri simple 'X', în timp ce un text cu mai multe litere se scrie între ghilimele duble "Salut"!

💡 Glosar de Noțiuni IT & Concepte Cheie

IDE (Integrated Development Environment)

Mediu software unificat ce conține editor de cod, compilator și depanator (ex: Code::Blocks).

Compilator

Program specializat care traduce instrucțiunile scrise în limbaj sursă C++ în cod mașină binar executabil.

Variabilă

Zonă de memorie alocată, caracterizată printr-un nume (identificator), un tip de date și o valoare stocată.

int

Tip de date fundamental C++ rezervat numerelor întregi, pozitive sau negative.

double

Tip de date C++ pentru numere reale cu virgulă mobilă de precizie dublă.

❓ Întrebări Frecvente & Auto-Evaluare

Q: Ce se întâmplă dacă uităm să punem punct și virgulă la sfârșitul unei linii?
R: Compilatorul se va opri cu o eroare de sintaxă („error: expected ';' before...”) și va refuza să creeze fișierul executabil până când eroarea nu este corectată.
Q: Cum se numesc corect variabilele în C++?
R: Numele (identificatorii) pot conține litere, cifre și caracterul underscore _, dar nu pot începe niciodată cu o cifră și nu pot conține spații sau caractere speciale (+, -, @).
