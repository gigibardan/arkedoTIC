1. Sorting & Searching Visual Arena (Synced Line-by-Line with C++)

Grades 7–8 · Array Sorting · O(n²)

Bubble Sort (Swapping Adjacent Pairs)

Repeatedly compares adjacent elements and swaps them if out of order. Larger values bubble up to the end of the array each pass.

Grade 8 · Minimum Selection · O(n²)

Selection Sort (Minimum Pick)

Finds the smallest remaining element in the unsorted tail and swaps it once into position i.

Grade 8 · Incremental Sort · O(n²)

Insertion Sort (Playing Card Method)

Works like sorting playing cards in your hand: picks each key and shifts larger sorted items rightward to insert it.

Grade 8 · Logarithmic Lookup · O(log₂ n)

Binary Search (Divide & Conquer)

On a SORTED array, checks the middle index and halves the remaining search space every step—1,000 items take at most 10 checks!

Grade 7 · Sequential Loop · O(n)

Linear Search (Sequential Scan)

Inspects items one by one from left to right. Works on unsorted arrays, but worst-case checks all n items.

3. Logic Gate Topologies & National Curriculum Bridges (Grades 5–8)

OUT = A · B

AND Gate

Outputs 1 (HIGH) ONLY when both A and B are 1 simultaneously (same as `&&` in C++).

OUT = A + B

OR Gate

Outputs 1 whenever AT LEAST one input is 1 (same as `||` in C++).

OUT = A ⊕ B

XOR Gate (Exclusive OR)

Outputs 1 ONLY when A and B differ (one 0, one 1). Core building block of binary addition & encryption!

OUT = ¬(A · B)

NAND Gate (Universal Gate)

Inverted AND: outputs 0 only when both inputs are 1. Any CPU circuit can be built purely from NAND gates!

SUM = A ⊕ B · CARRY = A · B

Binary Half-Adder (ALU Core)

Adds two binary bits inside the CPU! When A=1 & B=1, SUM=0 and CARRY=1 (1 + 1 = 10 binary = 2!).

SIREN = (A · B) + C

Smart Lab Security Circuit

Alarm rings if (Motion A AND Armed B) OR Emergency Panic C is pressed.

Frequently Asked Questions — Algorithms & CPU Lab

How does the Visual Algorithm Arena work for Bubble Sort, Selection, Insertion & Binary Search?
Every step animates on dual-coded bars (amber = comparing, coral = swapping, green = sorted, cyan = Binary Search mid) synced line-by-line with C++ pseudocode and live operation counters.
Why is Binary Search O(log n) dramatically faster than Linear Search?
On a sorted array it checks the midpoint and discards half of remaining items every step—1,024 elements take at most 10 checks instead of 1,024.
What do students learn inside the Von Neumann CPU Simulator?
Students watch instructions and data share unified RAM while the Control Unit runs Fetch (PC → IR), Decode, and Execute (ALU + Accumulator + Zero Flag) on live assembly programs.
