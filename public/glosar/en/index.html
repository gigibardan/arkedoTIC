Grades 5–8 · Algoritm și Proprietățile Algoritmilor

Algorithm & Core Algorithm Properties

An algorithm is a finite, unambiguous, step-by-step set of instructions that transforms input data into the desired output within a finite number of steps.

Grades 7–8 · Arduino UNO și Structura Schiței (setup & loop)

Arduino UNO & Sketch Structure (setup & loop)

Arduino UNO is an open-source microcontroller board (ATmega328P) widely used in school robotics and IoT projects. Every Arduino C++ sketch requires two functions: setup(), which runs once on power-up, and loop(), which repeats forever.

Grade 8 · Vector (Tablou Unidimensional) în C++

Array (1D Vector) in C++

A 1D array is an indexed collection of elements sharing the same data type stored contiguously in memory under a single name. In C++, native array indices start at 0.

Grades 7–8 · Atribuire (=) vs. Comparare Egalitate (==) în C++

Assignment (=) vs. Equality Check (==) in C++

A single equals sign (=) is the assignment operator that stores a value into a variable (x = 5). Double equals (==) is the comparison operator that tests whether two values are equal (x == 5).

Grade 5 · Bit și Byte (Octet) — Unități de Măsură ale Informației

Bit & Byte — Digital Information Units

A bit (b) is the smallest unit of digital data and holds a single binary value: 0 or 1. One Byte (B) equals 8 bits and is enough to store a single text character such as a letter or digit.

Grade 8 · Celulă, Domeniu și Referință Absolută ($A$1) în Excel

Cell, Range & Absolute Reference ($A$1) in Excel

A cell sits at a column-row intersection (like B4), and a range spans a block of cells (A2:A20). An absolute reference ($B$1) locks a cell with dollar signs so it stays fixed when dragging a formula with AutoFill.

Grades 7–8 · Cloud Computing, Backup și Colaborare (Google Drive / OneDrive)

Cloud Computing, Backups & Real-Time Collaboration

Cloud computing stores files and runs applications on remote internet servers rather than relying solely on your local computer drive. It enables automatic backups, version history, and simultaneous teamwork inside tools like Google Docs and OneDrive.

Lab & Theory Open Term →
Grade 8 · Erori Frecvente în Excel (#NAME?, #VALUE!, #DIV/0!, #REF!, ###)

Common Excel Formula Errors (#NAME?, #VALUE!, #DIV/0!, #REF!, ###)

Excel error codes diagnose exact formula issues: #NAME? means a misspelled function name, #VALUE! means mixing text with math, #DIV/0! means dividing by zero, #REF! means a deleted reference, and ### means the column is too narrow.

Grades 6–8 · Structura Alternativă (if / else și switch) în C++

Conditional Branching (if / else & switch) in C++

Conditional branching lets a program choose between different execution paths depending on whether a logical condition is true or false (if / else), or by matching discrete constant values (switch).

Grade 8 · Funcții de Bază în Excel: SUM, AVERAGE, MIN, MAX

Core Excel Functions: SUM, AVERAGE, MIN, MAX

SUM, AVERAGE, MIN, and MAX compute totals, arithmetic means, smallest values, and largest values across a cell range. Every spreadsheet formula must begin with an equals sign (=).

Grade 5 · Procesor (CPU — Central Processing Unit)

CPU (Central Processing Unit)

The CPU (Central Processing Unit) is the "brain" of a computer: the microchip mounted on the motherboard that fetches, decodes, and executes instructions every second for the operating system, school apps, and programs.

Grades 7–8 · Rezistor de Protecție & Legea lui Ohm (U = I · R)

Current-Limiting Resistor & Ohm’s Law (V = I · R)

A resistor limits electrical current in a circuit to protect LEDs and microcontroller pins from burning out. Using Ohm’s Law (V = I · R), an LED wired to a 5V Arduino pin requires a 220 Ω to 330 Ω series resistor.

Grades 5–8 · Cyberbullying, Amprenta Digitală & Linia de Ajutor 119

Cyberbullying & Digital Footprint

Cyberbullying is repeated, intentional online harassment through social media, messaging groups, or games (insults, rumors, exclusion, or sharing embarrassing photos without consent). Everything posted online leaves a lasting Digital Footprint.

Grades 7–8 · Pini Digitali, Analogici (ADC) și PWM (~) pe Arduino

Digital, Analog (ADC) & PWM (~) Arduino Pins

Digital pins (0–13) read or output strictly two states: HIGH (5V) or LOW (0V). Analog input pins (A0–A5) measure continuous sensor voltages from 0 to 1023, while PWM (~) pins output 0–255 duty cycles to dim LEDs or control motor speed.

Grades 5–7 · Formatare Text, Diacritice (RO) & Margini de Pagină în Word / Docs

Document Formatting, Headings & Page Margins (Word / Docs)

Clean document formatting relies on uniform page margins (2–2.5 cm), proper punctuation spacing (space after marks, never before), clean Page Breaks (Ctrl+Enter), and Heading styles (H1/H2) to generate an automatic Table of Contents.

Grade 5 · Extensia de Fișier (.docx, .pdf, .cpp, .png, .exe)

File Extension (.docx, .pdf, .cpp, .png, .exe)

A file extension is the short suffix after the last dot in a filename (like report.pdf). It tells the operating system what type of data the file holds and which application should open it.

Grades 7–8 · Bucla for (Structura Repetitivă cu Contor)

for Loop (Counter-Controlled Iteration)

A for loop executes a block of code a known number of times by packing the counter initialization, loop condition, and increment step into one compact header.

Grade 7 · Sisteme GIS, Hărți Digitale & Coordonate GPS (Latitudine / Longitudine)

GIS (Geographic Information Systems) & GPS Coordinates

A GIS (Geographic Information System) connects digital maps with location data organized in toggleable layers using GPS Latitude and Longitude coordinates to analyze routes, terrain, and landmarks.

Grade 8 · Senzor Ultrasonic HC-SR04 (Măsurarea Distanței cu Ultrasunete)

HC-SR04 Ultrasonic Distance Sensor

The HC-SR04 uses four pins (VCC, Trig, Echo, GND) to measure distance from 2 cm to 400 cm by sending a 10 µs ultrasonic pulse on Trig and timing the reflected sound wave return on Echo.

Hierarchical File Tree & File Path

A file tree is the hierarchical folder structure on a storage drive starting from a root directory (e.g., C:\ or /) down through nested subfolders. A file path specifies the exact address of a file inside that tree.

Grade 8 · HTML5 și Etichete Semantice (<header>, <main>, <article>, <img>)

HTML5 & Semantic Elements (<header>, <main>, <article>)

HTML5 (HyperText Markup Language) defines the structural skeleton of every webpage using markup tags. Semantic elements like <header>, <nav>, <main>, and <footer> communicate each section’s meaning to search engines and screen readers.

HTTP vs. HTTPS (SSL/TLS Encryption)

HTTP is the web protocol browsers use to fetch pages in plain text. HTTPS (HTTP Secure) wraps that traffic in SSL/TLS encryption so passwords and form inputs cannot be read in transit.

IP Address (IPv4/IPv6) & DNS (Domain Name System)

An IP address is the unique numeric identifier assigned to each device on a network (e.g., 192.168.1.1). DNS (Domain Name System) acts like the Internet’s phonebook, translating human-readable domains like arkyedu.com into numeric IP addresses.

Large Language Model (LLM) & AI Hallucinations

A Large Language Model (LLM) is an AI system trained on massive text datasets to predict the next likely token/word in context. An "AI hallucination" happens when the model confidently invents fake facts, quotes, or citations that sound convincing.

Logical Spreadsheet Functions: IF & COUNTIF

The IF function tests a condition and returns one result when true and another when false. COUNTIF counts how many cells in a range match a given criterion (such as scores >= 8).

Malware Types (Virus, Trojan, Ransomware, Spyware)

Malware (Malicious Software) covers any harmful program built to damage systems or steal data—including Viruses, Trojans disguised inside fake downloads, Spyware that logs passwords, and Ransomware that locks your files.

Grades 7–8 · Operatorul Modulo (%) și Împărțirea Întreagă (/) în C++

Modulo (%) & Integer Division (/) in C++

When both operands are integers in C++, / computes the integer quotient (discarding decimals), while modulo % returns the remainder. Together with base 10 (% 10 and / 10), they power digit-extraction and divisibility algorithms.

Netiquette (Internet Etiquette) is the set of respectful rules for online communication. In email, To holds primary recipients, Cc (Carbon Copy) sends visible copies to others, and Bcc (Blind Carbon Copy) hides recipients’ addresses from one another.

Grade 8 · Multitasking în Arduino: Funcția millis() vs. delay()

Non-Blocking Arduino Timing: millis() vs. delay()

The delay(ms) function freezes the entire Arduino processor during the pause, missing button presses and urgent sensors. The millis() function returns milliseconds since boot, letting multiple LEDs, buzzers, and sensors run simultaneously without blocking.
